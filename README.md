# ARIA — nouvelle application

Application web progressive indépendante. Publier les six fichiers à la racine du dépôt relié à Netlify.

Fonctions : Journée, Semaine, Mois, Année, objectifs illimités, tâches et événements modifiables, priorités, durée prévue, saisie du temps réel, proposition de planification hebdomadaire à valider, revue des tâches non faites avec choix individuel, bilans hebdomadaires archivés, export/import JSON.

Les données sont conservées localement dans le navigateur via localStorage. Elles ne sont pas synchronisées entre appareils et ne sont pas sauvegardées sur GitHub/Netlify. Exporter régulièrement une sauvegarde.
